milume

Notebook widgets for spatial omics that stay in sync with Python.

Draw landmarks and selections on tissue coordinates in AnnData. Persist hits as obs_names — analysis stays in the notebook.

pip install milume

LandmarksWidget

Lasso, rectangle, ellipse; point, line, spline, shape. Color by category or gene. Neighbor expand runs in the browser. Read selections back with get_obs_names.
