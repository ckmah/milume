# milume

Notebook widgets for spatial omics that stay in sync with Python.

- Install: `pip install milume`
- Documentation: https://ckmah.github.io/milume/docs/
- Repository: https://github.com/ckmah/milume
- Landmarks demo (molab): https://molab.marimo.io/github/ckmah/milume/blob/main/demos/landmarks.py
- Colon A2 demo (molab): https://molab.marimo.io/github/stellaromics/pyxa_scverse_demo/blob/main/colon_a2.py

LandmarksWidget draws selections and landmarks on tissue coordinates in AnnData or
SpatialData.
