# Keyboard shortcuts

Global navigation and panel shortcuts. Tool-specific keys (lasso, landmarks, Inspect, Probe) are on each [Widget UI](ui/index.md) page.

| Action | Keys |
|---|---|
| Select | <kbd>V</kbd> |
| Move | <kbd>H</kbd> |
| Pan while held (any tool) | <kbd>Space</kbd> |
| Zoom in / out | <kbd>=</kbd> / <kbd>-</kbd> |
| Reset view | <kbd>0</kbd> |
| Full screen | <kbd>F</kbd> |
| Collapse left / right panel | <kbd>[</kbd> / <kbd>]</kbd> |
| Deselect, cancel a draft | <kbd>Esc</kbd> |

See [Navigate](ui/navigate.md) for toolbar icons that match these keys.
