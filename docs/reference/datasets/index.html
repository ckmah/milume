tiny¶

Fields: Sub-megabyte committed fixtures under tests/data/ (xenium_ovary_subsample/, cosmx_synthetic_tiny/) plus the Hugging Face xsmall/ tree (100 µm cube cropped from small/; 187 cells kept whole with segmentation and counts).

Load: Test helpers and frontend harness scripts read the committed paths or snapshot_download(..., allow_patterns="xsmall/*") then spatialdata_io.experimental.pyxa. Coordinates are in micrometres (Pyxa metadata; Xenium as read by spatialdata_io).

Citation: Xenium ovary tiny — 10x Genomics public example data, CC BY 4.0. Pyxa xsmall/ — Stellaromics demo dataset, BSD-3-Clause (see HF README).

2D¶

Fields: AnnData with authors' log-normalized X (float32 CSR), layers['raw_counts'] (int32 CSR), obsm["spatial"] (µm), obs columns cell_type, cell_class, anatomical_layer, mucosal_pseudospace, and uns["cell_type_colors"]. 1,815 QC-pass genes for the slice (nnz 920,437; median 26 genes/cell and 48 raw counts/cell over those genes). Source obs['n_counts'] median 54 refers to the full panel, not this gene subset.

Load: import milume as ml then ml.ds.ileum_merfish_xu2026() or ml.datasets.ileum_merfish_xu2026() (ml.ds is the same module as ml.datasets). Downloads go to the user cache when the in-repo file is absent. From a checkout you can pass path="demos/data/ileum.h5ad". Registry metadata matches ml.datasets.info("ileum_merfish_xu2026") (Datasets API). Then milume.peek(adata, color="cell_type", genes=[...]) with a short preload list in notebooks so exports stay under the static payload budget; omit genes or pass genes=None to rely on on-demand loading for all 1,815 names. Do not re-normalize: X is already log-normalized.

Citation:

  • Xu RJ, Zhang H, Cadinu P, Nicol PB, Herrmann US, Lee T, Geistlinger L, Irizarry RA, Moffitt JR. Cell Host & Microbe 34(3):509–525.e13 (2026). doi:10.1016/j.chom.2026.01.018
  • Moffitt J, Xu R. Dryad (2025), version 5. doi:10.5061/dryad.p5hqbzm0z. CC0-1.0.

Provenance and regen: demos/data/README.md, demos/data/xu2026/.

3D¶

Fields: Pyxa folder layout: cell_by_gene_v1.csv, cell_metadata_v1.csv, segmentation_geometries_v1.parquet, zipped mosaic_3d.ome.zarr.zip (optional transcript CSV). Table coordinates in µm; Inspect uses the mosaic and per-z cell outline meshes.

Load: snapshot_download("Stellaromics/demo", allow_patterns="small/*", ignore_patterns="*cell_assigned_gene*") then pyxa(local_dir / "small", cell_assigned_gene=False) as in demos/landmarks.py. Write a SpatialData Zarr store if you need a stable path for Inspect. Clustering in the demo uses sc.pp.log1p on counts only for a colour column — not normalize_total.

Citation: Stellaromics Pyxa demo dataset, BSD-3-Clause. Colon attribution on the HF README applies to colon/, not small/.

full¶

Fields: Full human colon Pyxa export (colon/ on HF): ~5180 × 4230 × 128 µm, 492,155 cells, 1,020 genes, ~30 GB on disk when materialized.

Load: Stream or selectively snapshot_download columns/files you need (#134). Not bundled in git.

Citation: Stellaromics Pyxa demo dataset, BSD-3-Clause; Colon attribution on the HF README.
